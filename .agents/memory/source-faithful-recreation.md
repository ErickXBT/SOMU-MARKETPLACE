---
name: Source-faithful recreation
description: Reproducing a supplied UI should preserve its section sequence and proportions before adding visual polish.
---

When a user asks for a visual recreation with only a palette change, audit the implementation against the source's section order, spacing rhythm, responsive columns, and footer composition before considering it finished.

**Why:** Visual polish can unintentionally introduce new sections or alter layout structure even when the requested change is limited to colors.

**How to apply:** Keep the source as the structural contract; treat branding, copy, and color substitutions as controlled changes layered on top.
